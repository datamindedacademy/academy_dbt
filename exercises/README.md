# SQL and dbt exercises

Complete the [Databricks setup](../docs/setup_instructions.md#databricks-free-edition) before the exercises.
The exercise numbers match the slide deck.

| Part | Where to work | Exercises |
|---|---|---|
| SQL | Databricks SQL editor | [1–5](sql/) |
| dbt | Codespace terminal | [1–11](dbt/) |

Databricks supplies the source tables in `samples.tpch`.
Your dbt models appear in `workspace.dbt`.
The Postgres database in the Codespace is the backup.
