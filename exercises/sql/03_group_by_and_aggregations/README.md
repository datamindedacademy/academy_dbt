# SQL exercise 3: Aggregate results

Use `samples.tpch`. Write one query per task.

1. Find the highest total order price.
2. Count customers from Germany.
3. Calculate the average total order price for German customers.
4. Count customers per country. Show the largest counts first.
5. Calculate total and average order value per customer. Show the largest totals first.
6. List customers with more than 25 orders.
7. List customers with more than 15 orders whose total price exceeds `100000`.

Use `WHERE` to filter rows before aggregation. Use `HAVING` to filter the resulting groups.
In task 7, apply the price condition before the order count.
